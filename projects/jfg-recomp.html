Jet Force Gemini: Recompiled

October 10, 2026 • recomp

A native PC port of Jet Force Gemini (N64, US) for Windows and Linux, made by static recompilation. There is no emulator: the game's code is translated from your ROM and compiled for your PC. The game is 100% playable.

Downloads

Binaries: Latest JFG portable Build

Source: Source code and build instructions on GitHub

What You Need

No game code or assets are included, so you need your own Jet Force Gemini US ROM in .z64 format.

  • Windows 10/11 with a Direct3D 12 GPU, or Linux with a Vulkan GPU
  • The ROM saved as baserom.us.z64 in the project folder
# Windows
build_windows.bat
run_windows.bat

# Linux
./build_linux.sh && ./run_linux.sh

The first build takes 10-40 minutes. The README lists the tools to install first.

Features

  • Dual-stick and mouse-and-keyboard controls, with over-the-shoulder aiming and rebindable buttons
  • Profiles: Default (the original game), Modern, Modern and Balanced, Extreme, and your own
  • Widescreen, ambient occlusion, bloom and longer draw distance
  • HD texture packs, switched in-game, plus texture dumping
  • Skippable cutscenes, and adjustable damage, movement and weapon stats
  • A tools toolbar with cheats, level warp and an items editor
  • A fly camera for screenshots

Modding

The port loads mods: .nrm files in bin/mods/, switched on and off and ordered in the Mods tab of the settings menu. A mod can add new planets and whole galaxies to the planet map, new levels, reskinned enemies, its own music, Lua scripts and weapon tuning, change the game's own levels, or patch the game's code.

  • The JFG Modding Wiki: how to make mods, step-by-step tutorials, and what the modding API can do so far
  • JFG-Studio: a level and modpack editor. Place squads, doors, keys, pickups and exits on your own geometry, set up planets and galaxies, add triggers, scripts and music, then build the pack and play it with one button
  • jfg64: a Blender add-on for modelling levels for JFG-Studio

Studio reads your own ROM; nothing from the game is in what it makes.

How It Works

The port uses N64Recomp to translate the game's code, N64ModernRuntime in place of the N64 operating system, and RT64 for rendering. It is built on cyscott/dkr-recomp.
