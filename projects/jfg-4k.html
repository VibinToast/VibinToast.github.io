Jet Force Gemini 4K Texture Pack

October 10, 2026 • textures

A HD texture pack for Jet Force Gemini: Recompiled using Real-ESRGAN for upscaling.

Please refer to Texture Pack Doc to get started creating your own.

Original vs HD

Drag the slider across each picture to compare the original textures with the HD pack. Use the Fullscreen button for a closer look; the arrows there step through the pictures.

  • 4K HD Texture Pack (zip, 4.4 GB)

This is the 4K pack. 2K and 1K versions will come later.

Install

Unzip the pack into the folder that holds the game's executable, so it ends up looking like this:

texture_packs\texture_name.rtz

Early Alpha

This is an early alpha, so expect visual bugs:

  • Fonts
  • Scrolling textures
  • Noticeable seams
  • Warped textures
