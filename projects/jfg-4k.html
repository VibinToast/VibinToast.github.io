Jet Force Gemini HD Texture Pack

October 10, 2026 • textures

A HD texture pack for Jet Force Gemini: Recompiled using Real-ESRGAN for upscaling.

Please refer to Texture Pack Doc to get started creating your own.

Github: Jet Force Gemini HD Texture Pack

Original vs HD

Drag the slider across each picture to compare the original textures with the HD pack. Use the Fullscreen button for a closer look; the arrows there step through the pictures.

Download

The easiest way is the game's launcher (Recompiled 1.2 or later): turn on Check for Updates and Official HD Texture Pack, and it downloads and installs the pack, and offers an Update when a new version is out.

Or download one pack by hand:

  • 1K HD Texture Pack v1.1.1 (rtz, 198 MB) (Recommended for most!)

  • 2K HD Texture Pack v1.1.1 (rtz, 782 MB)

  • 4K HD Texture Pack v1.1.0 (rtz, 3.0 GB, in two parts): part 1 and part 2. Download both.

All files are on the latest release.

Install

Put the .rtz file in the game's texture_packs folder, then pick it on the Textures page or press F6 in game to cycle through packs. The launcher's Open Texture Packs Folder button opens the folder for you.

  • Windows: texture_packs\ next to JetForceGeminiRecompiled.exe
  • Linux AppImage and Steam Deck: ~/.local/share/JetForceGeminiRecompiled/texture_packs/
  • Linux portable (tar.gz): texture_packs/ inside the game folder

4K: put both parts in texture_packs. The game joins them into one pack by itself the next time it starts, then removes the parts. To join them yourself, see the texture pack README.

Early Alpha

This is an early alpha, so expect visual bugs:

  • Fonts
  • Scrolling textures
  • Noticeable seams
  • Warped textures
