## Download

The easiest way is the game's launcher (Recompiled 1.2 or later): turn on **Check for Updates** and **Official HD
Texture Pack**, and it downloads and installs the pack, and offers an **Update** when a new version is out.

Or download one pack by hand:

- [1K HD Texture Pack v1.1.1](https://github.com/VibinToast/JetForceGemini-HD_TexturePack/releases/download/v1.1.1/Official_Recomp_HD-1K_v1.1.1.rtz) (rtz, 198 MB) (Recommended for most!)

- [2K HD Texture Pack v1.1.1](https://github.com/VibinToast/JetForceGemini-HD_TexturePack/releases/download/v1.1.1/Official_Recomp_HD-2K_v1.1.1.rtz) (rtz, 782 MB)

- 4K HD Texture Pack v1.1.0 (rtz, 3.0 GB, in two parts): [part 1](https://github.com/VibinToast/JetForceGemini-HD_TexturePack/releases/download/v1.1.1/Official_Recomp_HD-4K_v1.1.0.rtz.001) and [part 2](https://github.com/VibinToast/JetForceGemini-HD_TexturePack/releases/download/v1.1.1/Official_Recomp_HD-4K_v1.1.0.rtz.002). Download both.

All files are on the [latest release](https://github.com/VibinToast/JetForceGemini-HD_TexturePack/releases/latest).

## Install

Put the `.rtz` file in the game's `texture_packs` folder, then pick it on the Textures page or press F6 in game to
cycle through packs. The launcher's **Open Texture Packs Folder** button opens the folder for you.

- **Windows:** `texture_packs\` next to `JetForceGeminiRecompiled.exe`
- **Linux AppImage and Steam Deck:** `~/.local/share/JetForceGeminiRecompiled/texture_packs/`
- **Linux portable (tar.gz):** `texture_packs/` inside the game folder

**4K:** put both parts in `texture_packs`. The game joins them into one pack by itself the next time it starts, then
removes the parts. To join them yourself, see the
[texture pack README](https://github.com/VibinToast/JetForceGemini-HD_TexturePack#the-4k-pack-comes-in-two-parts).

A native PC port of Jet Force Gemini (N64, US) for Windows and Linux, made by static recompilation. There is no emulator: the game's code is translated from your ROM and compiled for your PC. The game is 100% playable.

## Downloads

Binaries: [Latest JFG portable Build](https://github.com/VibinToast/JetForceGemini-Recomp/releases/latest)

Source: [Source code and build instructions on GitHub](https://github.com/VibinToast/JetForceGemini-Recomp)

## What You Need

No game code or assets are included, so you need your own Jet Force Gemini US ROM in `.z64` format.

- Windows 10/11 with a Direct3D 12 GPU, or Linux with a Vulkan GPU
- The ROM saved as `baserom.us.z64` in the project folder

```
# Windows
build_windows.bat
run_windows.bat

# Linux
./build_linux.sh && ./run_linux.sh
```

The first build takes 10-40 minutes. The [README](https://github.com/VibinToast/JetForceGemini-Recomp#build-and-run) lists the tools to install first.

## Features

- Dual-stick and mouse-and-keyboard controls, with over-the-shoulder aiming and rebindable buttons
- Profiles: Default (the original game), Modern, Modern and Balanced, Extreme, and your own
- Widescreen, ambient occlusion, bloom and longer draw distance
- HD texture packs, switched in-game, plus texture dumping
- Skippable cutscenes, and adjustable damage, movement and weapon stats
- A tools toolbar with cheats, level warp and an items editor
- A fly camera for screenshots

## Modding

The port loads mods: `.nrm` files in `bin/mods/`, switched on and off and ordered in the Mods tab of the settings menu.
A mod can add new planets and whole galaxies to the planet map, new levels, reskinned enemies, its own music, Lua
scripts and weapon tuning, change the game's own levels, or patch the game's code.

- [The JFG Modding Wiki](https://jfg.vibintoast.com): how to make mods, step-by-step tutorials, and what the modding
  API can do so far
- [JFG-Studio](https://github.com/VibinToast/JFG-Studio): a level and modpack editor. Place squads, doors, keys,
  pickups and exits on your own geometry, set up planets and galaxies, add triggers, scripts and music, then build the
  pack and play it with one button
- [jfg64](https://github.com/VibinToast/jfg64-blender): a Blender add-on for modelling levels for JFG-Studio

Studio reads your own ROM; nothing from the game is in what it makes.

## How It Works

The port uses [N64Recomp](https://github.com/N64Recomp/N64Recomp) to translate the game's code, [N64ModernRuntime](https://github.com/N64Recomp/N64ModernRuntime) in place of the N64 operating system, and [RT64](https://github.com/rt64/rt64) for rendering. It is built on [cyscott/dkr-recomp](https://github.com/cyscott/dkr-recomp).
